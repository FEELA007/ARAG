# ARAG — Adaptive, Reliable & Cost-Aware Retrieval-Augmented Generation

**Current application:** custom HTML/CSS/JavaScript UI + FastAPI backend + three retrieval tiers.

Start with [`README_ADVANCED.md`](README_ADVANCED.md) for installation, tier limits, model architecture, token settings, and evaluation instructions. The earlier Streamlit low-version interface remains in `arag/gui/app.py` for reference; the recommended UI for this build is served at `http://127.0.0.1:8000` by `backend.app`.
