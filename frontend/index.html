About ARAG Advanced

ARAG follows the project architecture: document extraction and chunking, embeddings, vector retrieval, BM25 hybrid search, reciprocal-rank fusion, optional cross-encoder reranking, evidence checks, grounded generation and citations.

The three tiers use different retrieval pipelines and resource limits. The 75%, 85%, and 95% values are targets only; actual answer accuracy must be measured against a labelled benchmark.
